Google Sheets Setup

Connect the knowledge checks to a Google Sheet so results log automatically by site — Teleperformance and TaskUs each get their own tab.

1
Create a new Google Sheet with two tabs
  • Go to sheets.google.com and click + Blank
  • Name it something like Payroll Training — Quiz Results
  • At the bottom, rename the default tab to Teleperformance (right-click → Rename)
  • Click the + to add a second tab and name it TaskUs
  • Add these headers to row 1 on both tabs:
Teleperformance
TaskUs
A — Timestamp B — Email C — Site D — Phase E — Score F — Total G — Result
4/14/2026, 9:32 AM jordan.lee@gusto.com Teleperformance Phase 1 13 15 Pass
4/14/2026, 10:05 AM alex.rivera@gusto.com Teleperformance Phase 2 10 15 Fail
Tip: Bold the header row on both tabs and freeze it (View → Freeze → 1 row).
2
Open Apps Script and paste the logging code
In your Google Sheet, click Extensions → Apps Script. A new tab opens with the script editor.

Delete any existing code, then paste in the following: 
function doGet(e) {
  try {
    const ss   = SpreadsheetApp.getActiveSpreadsheet();
    const p    = e.parameter;

    // Route to the correct tab based on site selection
    const siteName = (p.site === 'TaskUs') ? 'TaskUs' : 'Teleperformance';
    let sheet = ss.getSheetByName(siteName);

    // Auto-create the tab if it doesn't exist yet
    if (!sheet) {
      sheet = ss.insertSheet(siteName);
      sheet.appendRow([
        'Timestamp', 'Email', 'Site',
        'Phase', 'Score', 'Total', 'Result'
      ]);
    }

    sheet.appendRow([
      new Date().toLocaleString(),  // Timestamp
      p.email  || 'unknown',          // Gusto Care email
      siteName,                          // Teleperformance or TaskUs
      p.phase  || '',                 // Phase 1 or Phase 2
      parseInt(p.score) || 0,         // Score (e.g. 13)
      parseInt(p.total) || 15,        // Total questions
      p.passed || '—'                 // Pass or Fail
    ]);

    return ContentService
      .createTextOutput('OK')
      .setMimeType(ContentService.MimeType.TEXT);

  } catch(err) {
    return ContentService
      .createTextOutput('Error: ' + err.message)
      .setMimeType(ContentService.MimeType.TEXT);
  }
}
Click the 💾 Save icon (Ctrl/Cmd+S) to save.
3
Deploy as a web app
  • Click Deploy (top right) → New deployment
  • Click the gear icon ⚙ → choose Web app
  • Set the options:
    • Description: Quiz Results Logger
    • Execute as: Me
    • Who has access: Anyone
  • Click Deploy → authorize if prompted
  • Copy the Web app URL — it ends in /exec
⚠️ Important: Use the /exec URL, not the /dev URL. "Anyone" access (not "Anyone with a Google account") is required — otherwise learners who aren't signed in to Google will fail to log results.
4
Paste the URL into the training page
Open payroll-training.html in any text editor and find this line near the top of the <script> block: 
const SHEET_SCRIPT_URL = 'PASTE_YOUR_APPS_SCRIPT_URL_HERE';
Replace the placeholder with your URL: 
const SHEET_SCRIPT_URL = 'https://script.google.com/macros/s/AKfyc.../exec';
Save the file.
Done! Results will now flow automatically into the correct tab — Teleperformance agents go to the Teleperformance tab, TaskUs agents go to the TaskUs tab — the moment they finish any knowledge check.
5
Test it
  • Open the training page from Phase 1 (click the Phase 1 card on the hub)
  • Navigate to the last module and click ✓ Knowledge Check
  • Enter a test email, select a site, and complete the quiz
  • Check your Google Sheet — a new row should appear in the matching tab within a few seconds
If nothing appears: The most common cause is deploying with "Anyone with a Google account" instead of "Anyone." If you need to change this, create a new deployment (not an update) and copy the new /exec URL into the training page.

✅ Setup Complete

Every completed knowledge check now logs the learner's email, site, phase, score, and pass/fail to the correct tab in your Google Sheet automatically.
